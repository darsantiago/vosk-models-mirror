# Vosk Models Mirror

Static mirror of Vosk small language models for [VisionPhone](https://github.com/darsantiago/visionphone) on-device voicemail transcription. Fallback for when https://alphacephei.com/vosk/models/ is unreachable.

Models in [Releases](https://github.com/darsantiago/vosk-models-mirror/releases). Files are byte-identical to upstream.
